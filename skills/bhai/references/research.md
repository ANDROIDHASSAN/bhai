# What the research says, and the rule it gives bhai

| Finding | Source | Rule in bhai |
|---|---|---|
| Agent PRs are merged less than human ones: in AIDev, Codex ~64%, Devin ~49%, Copilot ~35% vs ~77–79% for humans; bug-fix subset 71% vs 88% | AIDev (arXiv 2507.15003); "Bug-Fixing in the Age of AI" (ACM 2026); MSR 2026 task-stratified analysis | assume a reviewer is skeptical; every gate exists to close that gap |
| Of 306 rejected agent fixes with a known reason: inactivity 17%, CI failure 7%, superseded 6%, incorrect fix 6%, wrong approach 3%, agent failure 8% | "Understanding the Rejection of Fixes Generated by Agentic PRs" (arXiv 2606.13468) | follow-up route keeps PRs alive and green; re-search duplicates right before opening; reproduce before fixing; read how maintainers prefer it fixed |
| Unmerged agent PRs are larger, touch more files, and fail CI more often; duplicates and unwanted features are common reasons | study of ~33k agent PRs, as reported in OSS-policy write-ups | smallest diff, local CI before CI, no features without an issue |
| Authors recommend: tell agents the preferred approach, how to run tests, and only give them relevant, high-priority work | arXiv 2606.13468 | read AGENTS.md/CONTRIBUTING/review comments first; run the repo's own checks; skip low-value candidates |
| A few factors explain most PR decisions over ~3.3M PRs; failed builds matter where CI exists | Zhang, Yu, Gousios, Rastogi (TSE 2023, arXiv 2105.13970) | green CI is non-negotiable |
| Test cases, code quality and the importance of the area drive acceptance (integrator survey) | Gousios et al., ICSE 2014/2016 | a failing-then-passing test in every PR; fix things users hit |
| AI-generated PRs carried ~1.7x more defects in one 44k-PR analysis | CodeRabbit analysis, as reported | mutation check, edge cases, self-grill after the fix |
| Projects now ban or gate AI PRs: Ghostty (AI PRs only for pre-approved issues), tldraw (auto-closes external PRs), LLVM (no autonomous agents without human approval), curl ended its bug bounty over AI slop | maintainer policies, Jan–2026 coverage | read the AI policy first and refuse where it forbids; a human approves and can explain every PR |
